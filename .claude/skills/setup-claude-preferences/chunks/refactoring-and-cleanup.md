## Refactoring and Cleanup

Proceed with cleanup or refactoring the user requests, including when it expands the original ticket or PR scope. Do not redirect requested work to a separate PR or follow-up issue unless the user asks.

Keep unsolicited refactoring focused on code directly affected by the task. Ask before broadening into unrelated cleanup.

When useful for review, separate behavior changes and cleanup into distinct commits without moving either out of the requested work.
